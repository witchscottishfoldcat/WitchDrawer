# 结构重构手工冒烟清单

用途：结构重构期间每个阶段末尾人工跑一遍，补偿单元测试覆盖不到的 UI 时序行为（悬停延迟、弹窗定位、拖拽捕获）。任何一步行为与重构前不一致即停止并回滚最近提交。

执行环境：Release 构建（`src/WitchDrawer.App/bin/Release/net10.0-windows/WitchDrawer.App.exe`）。

## 盒子窗口基础

- [ ] 拖动盒子标题栏/表面移动窗口，松手后位置保存（重启后恢复）
- [ ] 盒子拖到屏幕边缘/右下角，松手后被工作区钳回，不被屏幕吞边
- [ ] Win+D 显示桌面后再按 Win+D，盒子重新出现且不被桌面吞掉
- [ ] 拖动一个盒子靠近另一个盒子：出现吸附对齐，虚线辅助线在两侧盒边缘显示/消失
- [ ] 位置锁定开启后盒子无法拖动，解锁后恢复

## 抽屉盒

- [ ] 拖拽抽屉封面右下角手柄调整大小：尺寸按半格吸附，无肉眼可见残缺格
- [ ] 封面磁贴单击选中（蓝框）、双击打开、右键出菜单
- [ ] 点击"展开"磁贴：二级弹窗弹出（缩放动画正常），点击外部关闭
- [ ] 弹窗打开期间鼠标悬停其上不触发关闭；拖拽弹窗内磁贴可正常发起拖动
- [ ] 卷起/展开切换动画正常，卷起状态下悬停标题栏按设置展开、移开后收回

## 映射盒

- [ ] 网格/列表视图切换动画正常，切换后位置不漂移
- [ ] 拖拽列表右缘手柄调整宽度，重启后保持
- [ ] 列表模式拖文件到指定行：插入线指示正确，落点正确

## 待办盒
