# WitchDrawer v1.4.4

## 界面与使用体验

- 新增 English 和简体中文界面，在设置中即时切换并保存选择；首次启动跟随系统语言，其他系统语言使用英语。
- 将桌面盒子透明度、盒子边线透明度、图标背景框透明度和“编辑页跟随透明度”统一纳入“自定义样式”，与颜色、圆角等选项一起展开或收起。
- 修复显示器、分辨率或缩放变化后桌面收纳盒布局恢复的问题。
- 检查更新和下载更新支持取消；下载停滞或超过总时限时结束操作并清理未完成的下载。

## 修复与安全性

- 映射盒拖入文件时使用引用语义，避免向拖放来源报告移动操作；普通盒仅接受可移动的文件拖放。
- 修复取消文件拖动时可能误触发移出操作的问题，包括 Esc 和多鼠标按键取消。
- 安装程序与设置统一使用开机启动项，并迁移旧版启动快捷方式，避免关闭开机自启动后仍由旧快捷方式启动。
- 卸载只移除安装程序拥有的文件，保留安装目录中的自定义数据，并清除旧版卸载日志中的递归删除规则；启动项清理检查其归属。
- 数据目录可写性检查使用独立临时文件，避免覆盖同名文件。
- 日志写入和旧日志清理改为后台处理，导出诊断日志和退出前刷新待写内容；完善内容加载的异常记录与资源清理。

## 下载

- 安装版：`WitchDrawer-Setup-v1.4.4-x64.exe`
- 安装版校验：`WitchDrawer-Setup-v1.4.4-x64.exe.sha256`
- 便携版：`WitchDrawer-v1.4.4-win-x64.zip`
- 便携版校验：`WitchDrawer-v1.4.4-win-x64.zip.sha256`

安装版和便携版均为 Windows x64 自包含版本，无需另行安装 .NET 运行时。便携版请完整解压 ZIP 后运行 `WitchDrawer.App.exe`。
