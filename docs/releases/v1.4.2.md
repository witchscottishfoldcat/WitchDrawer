# WitchDrawer v1.4.2

## 修复内容

- 修复“以管理员身份运行”时自动降权失败、提示错误码 5 后退出的问题。现在保留用户选择的启动权限，继续正常启动。
- 管理员权限运行时，在主窗口状态栏提示：从普通权限桌面或窗口拖入文件受 Windows 限制。需要桌面拖放时，请以普通权限启动。
- 权限状态检查在后台执行；检查失败仅记录日志，不阻止程序启动。

## 下载

- 安装版：`WitchDrawer-Setup-v1.4.2-x64.exe`
- 安装版校验：`WitchDrawer-Setup-v1.4.2-x64.exe.sha256`
- 便携版：`WitchDrawer-v1.4.2-win-x64.zip`
- 便携版校验：`WitchDrawer-v1.4.2-win-x64.zip.sha256`

安装版和便携版均为 Windows x64 自包含版本，无需另行安装 .NET 运行时。便携版请完整解压 ZIP 后运行 `WitchDrawer.App.exe`。
