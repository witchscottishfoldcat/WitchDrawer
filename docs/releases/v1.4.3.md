# WitchDrawer v1.4.3

## 新增功能

- 桌面收纳盒右键新增复制文件、粘贴、重命名和复制文件路径。文件剪贴板与 Windows 资源管理器互通，盒子空白处也可右键粘贴。
- 支持 `Ctrl+C` 复制文件、`Ctrl+V` 粘贴、`F2` 重命名、`Ctrl+Shift+C` 复制当前文件路径。
- 快捷方式右键可直接打开目标所在位置，并保留打开快捷方式文件自身位置的入口。文件夹也会在其父目录中被选中。

## 修复与安全性

- 修复普通盒中的文件被外部删除后，无法移除收纳项或删除盒子的问题。确认文件已不存在时只清理收纳记录；文件不可访问或存在待恢复操作时保留记录。
- 普通/像素盒粘贴创建副本并保留源文件，重名自动添加数字后缀。重命名后，移出或删除盒子会按新名称还原文件。
- 映射盒粘贴只加入绝对路径引用，重命名只修改引用显示名称。
- 复制与重命名通过 Core 文件服务执行，并记录恢复日志；数据库保存失败或操作中断时可重试恢复。无法判断的恢复状态保留相关文件供核对。
- 优化右键菜单的选择状态、位置和关闭时机，操作前重新查询文件当前路径；修复右键双击可能打开项目的问题。Shell 定位和管理员启动在后台执行。

## 下载

- 安装版：`WitchDrawer-Setup-v1.4.3-x64.exe`
- 安装版校验：`WitchDrawer-Setup-v1.4.3-x64.exe.sha256`
- 便携版：`WitchDrawer-v1.4.3-win-x64.zip`
- 便携版校验：`WitchDrawer-v1.4.3-win-x64.zip.sha256`

安装版和便携版均为 Windows x64 自包含版本，无需另行安装 .NET 运行时。便携版请完整解压 ZIP 后运行 `WitchDrawer.App.exe`。
