# WitchDrawer v1.4.0

## 更新内容

- 新增按主题独立保存的自定义样式：可调整盒子与图标圆角、背景色、悬停效果、选中色和强调色，支持单项重置及恢复原始预设。
- 优化主题设置的实时预览、透明度滑块和重置控件，数值显示对应单位。
- 改善启动、内容刷新、拖放及图标加载响应，减少重复读取和后台工作。
- 优化主页文件列表、待办页面及收纳盒设置布局，并修复桌面图标切换与显示设置弹窗问题。

## 稳定性修复

- 更新检查、确认、下载和重启采用完整的互斥流程，避免重复下载或同时启动多个更新器。
- 断网、服务器错误及无效更新响应会明确提示检查失败。
- 映射源文件被删除、改名或所在磁盘离线时，仍可通过右键菜单移除引用。
- 数据目录迁移的目录准备、锁获取、文件扫描和可写性探测均在后台执行。
- 加强文件操作恢复与 Windows 集成边界，并补充更新、映射项删除和数据迁移的回归测试。

## 下载

- 安装版：`WitchDrawer-Setup-v1.4.0-x64.exe`
- 安装版校验：`WitchDrawer-Setup-v1.4.0-x64.exe.sha256`
- 便携版：`WitchDrawer-v1.4.0-win-x64.zip`
- 便携版校验：`WitchDrawer-v1.4.0-win-x64.zip.sha256`

便携 ZIP 包含完整运行文件，可直接解压使用；安装版和便携版均为 Windows x64 自包含版本，无需另行安装 .NET 运行时。
