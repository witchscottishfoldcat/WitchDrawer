# WitchDrawer v1.4.1

## 更新内容

- 改善 Windows 11 专业工作站版 23H2 的桌面收纳盒层级兼容性，通过窗口事件修复显示桌面后的盒子可见性；其他系统继续使用原有桌面宿主方式。
- 保留鼠标点击与悬停输入，避免收纳盒抢占前台焦点。
- 修复跨盒移动、重名处理后内容刷新仍使用旧路径或名称的问题；仅位置变化时保留现有项目实例，减少图标重复加载。
- 文件检查与 Shell 打开放到后台 STA 线程，减少慢盘、网络路径或 Shell 扩展造成的界面阻塞。

## 稳定性修复

- 更新失败回滚时仅恢复发布包中的程序文件，保留包外用户数据在更新启动后的新增、修改和删除。
- 数据目录迁移仅在锁共享冲突时等待重试；路径等永久性错误会及时返回，避免持续等待。
- 补充鼠标激活、桌面层事件、更新回滚、内容刷新、Shell 打开及迁移锁的回归测试，并修复重启测试的进程清理竞态。

## 下载

- 安装版：`WitchDrawer-Setup-v1.4.1-x64.exe`
- 安装版校验：`WitchDrawer-Setup-v1.4.1-x64.exe.sha256`
- 便携版：`WitchDrawer-v1.4.1-win-x64.zip`
- 便携版校验：`WitchDrawer-v1.4.1-win-x64.zip.sha256`

安装版和便携版均为 Windows x64 自包含版本，无需另行安装 .NET 运行时。便携版请完整解压 ZIP 后运行 `WitchDrawer.App.exe`。
